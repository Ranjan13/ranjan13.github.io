# Ranjan Satapathy — AI Research & Translation

A simple static portfolio for GitHub Pages, with no build dependencies.

## Local preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000.

## Files and content

- `index.html`: profile and photo, research summary, applied research areas, selected Trustworthy AI and Finance publications, student tabs, and a collaborator sidebar. Mentoring and contact details sit within the introduction.
- `css/translational.css`: responsive ivory, navy, and teal theme.
- `js/translational.js`: footer year and accessible vertical student tabs with keyboard navigation.
- Existing portrait, CV, thesis, and legacy assets remain in the repository.

Profile, project, and mentoring details draw on the original public homepage and accompanying local portfolio. Review wording for currency before publication. Google Scholar links to the full publication list.

## Publishing

GitHub Pages serves the repository root from `master`. Changes can be reviewed on a separate branch and merged into `master` to publish. No build step is required.
